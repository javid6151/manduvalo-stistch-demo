# Manduva Logillu Furniture's

> Vintage & Luxury Heritage Wooden Furniture in Hyderabad (Moinabad)

A modern Vite + React web application showcasing authentic South Indian courtyard architecture, antique swings (Oonjal), hand-carved pillars, bespoke teakwood furniture, and showroom consultation.

## 🚀 Local Development

```bash
npm install
npm run dev
```

## 📦 Production Build

```bash
npm run build
npm run preview
```

## 🌐 Deployment (Vercel)
- **Framework Preset**: Vite
- **Build Command**: `vite build`
- **Output Directory**: `dist`
